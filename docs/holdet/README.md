# Holdet

Én fil pr. person. Din første pull request er at tilføje din egen: `docs/holdet/<dit-fornavn>.md`.

Skriv tre ting:

1. Dit navn og hvad du kan (også gerne "jeg har aldrig lavet en pull request før").
2. Hvad du gerne vil lave i ugen i Spanien.
3. Hvad du helst vil have hjælp til.

Se [Første dag](../foerste-dag.md).
